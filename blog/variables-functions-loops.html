Variables, functions and loops: the same ideas everywhere

5 min read

Languages look different on the surface, but nearly all of them are built from the same few pieces. Learn these and new languages feel familiar.

Variables: named boxes for values

A variable is a name that points to a value stored in memory. You can read it or change it later.

age = 21          # Python
let age = 21;     // JavaScript
int age = 21;     // C or Java

Functions: reusable recipes

A function takes inputs, does some work and gives back a result. Writing code once as a function means you can use it many times and fix bugs in one place.

def area(width, height):
    return width * height

print(area(3, 4))   # 12

Conditions: making choices

An if statement runs code only when something is true. This is how a program reacts to different situations.

if age >= 18:
    print("adult")
else:
    print("minor")

Loops: repeating work

A loop repeats code so you do not copy and paste it. A for loop goes through a collection. A while loop continues until a condition becomes false.

for n in [1, 2, 3]:
    print(n * 2)    # 2, 4, 6

Putting it together

Almost every program, from a calculator to a game, is these pieces combined: store values, make decisions, repeat steps, and wrap the useful parts in functions. The skill of programming is breaking a big problem into small steps made of these blocks.
